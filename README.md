# pchela.shop

Платформа прямых поставок мёда: поставщики публикуют пасеку и доступные партии, магазины ищут производителей по расстоянию, цене, объёму и признакам качества и отправляют заявки.

## Локальный запуск

```powershell
npm install
$env:NODE_ENV = 'development'
npm run dev
```

Сайт откроется на `http://127.0.0.1:3031`. При первом старте SQLite-база создаётся автоматически и наполняется демонстрационными карточками, явно отмеченными как примеры.

Регистрации, сессии, кабинеты поставщиков и закупщиков сохраняются в SQLite. Email из `ADMIN_EMAIL` получает административный доступ при регистрации или следующем запуске приложения; пароль пользователь задаёт только сам в форме регистрации.

## Проверки

```powershell
npm test
npm run check
npm run build
```

## Production

Приложение ожидает Node.js 24+, запускается командой `npm start` и отдаёт `/health` для проверки процесса. В production Nginx проксирует запросы на `127.0.0.1:3031`.
